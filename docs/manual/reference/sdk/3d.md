`raea/3d` holds what a scene uses beyond Bevy's own components: glTF models (`<Model>`, `<Part>`), physics and soft
bodies (`<Physics>`, `<Body>`, `<Goo>`), Gaussian splats (`<Splat>`), matchmoves, instancing and scattering, grass,
fire, decals, 3D text, and custom shader passes (`<FramePass>`, `<MeshPass>`, `<Compute>`). It also re-exports the
primitives and effects most scenes need, so a quick scene can import from one path. Bevy's camera, lights,
materials and meshes are under [`raea/camera`](camera.md), [`raea/light`](light.md), [`raea/pbr`](pbr.md) and
[`raea/mesh`](mesh.md), named as Bevy names them.

```tsx
import { AbsoluteFill, staticFile } from "raea";
import { Model, Physics } from "raea/3d";
import { Camera3d } from "raea/camera";
import { DirectionalLight } from "raea/light";
import { Transform } from "raea/transform";

function Scene() {
  return (
    <AbsoluteFill style={{ background: "#14161c" }}>
      <Camera3d transform={Transform.fromXyz(0, 1.6, 5).lookingAt([0, 0.5, 0])} />
      <DirectionalLight transform={Transform.fromXyz(3, 5, 4).lookingAt([0, 0, 0])} illuminance={11200} shadow_maps_enabled />
      <Model src={staticFile("media/chair.glb")} />
    </AbsoluteFill>
  );
}
```

See [3D](../../guides/3d.md) for building, lighting and checking a scene.

## Components

### `AmbientOcclusion`

Screen-space ambient occlusion: creases, corners and the ground under things darken where the sky's and the room's
light can't reach. It darkens ambient and environment light (an <AmbientLight>, an <Environment>), not the direct
light of a sun or a lamp. Turns multisampling off, so the edges are smoothed by SMAA instead (see <AntiAliasing>).
Put it inside the Canvas3D, once; each frame's is its own, so a shot can have it and the next not.

Bevy: `bevy_pbr::ssao::ScreenSpaceAmbientOcclusion`.

Takes [`AmbientOcclusionProps`](#ambientocclusionprops)'s props.
